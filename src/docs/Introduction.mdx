# Solae design system

Solae makes modest, modern swim sets for teen girls: a one-piece and matching shorts. This Storybook holds the design tokens, the component library and the mock website, all in React and TypeScript.

The brief was **elegant and simple**, with **three colours only**, **fluid type**, and section-by-section ideas from the inspiration boards.

## Three colours

The whole interface uses three hues from the Brand Starter, and their tints and shades:

Even the "neutrals" come from these: body text is Lagoon 900, headings Lagoon 950, and the page is Sunshine 50. The swimsuit collection colours appear only on products and their swatches, as the Brand Starter asks.

## How it is built

- **Tokens** live in `src/tokens/*.ts`. `npm run tokens` writes them to `src/styles/tokens.css` (CSS variables) and `tokens/tokens.json` (W3C design-token format, ready for Figma Tokens Studio).
- **Fluid type and space** grow smoothly between a 360px phone and a 1440px desktop with `clamp()`. Resize the canvas to see it.
- **Components** live in `src/components`, one folder each, styled with CSS Modules that read only the semantic tokens.
- **The website** lives in `src/site`, built only from the library.
